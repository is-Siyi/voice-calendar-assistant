# 语音日历助手

一个以语音交互为核心的日历管理工具，面向 XEngineer 新工科计划「语音版的日历工具」议题。

## 项目背景

很多人在管理日历时，真正麻烦的不是打开日历，而是把自然语言里的时间、事项和提醒快速整理成结构化日程。例如：

- 明天下午三点提醒我开会
- 查看今天的安排
- 删除明天下午三点的开会提醒

本项目希望用更接近真实说话习惯的方式，帮助用户快速完成添加、查看、删除日程提醒。

## 核心功能

- 语音添加日程：识别自然语言中的日期、时间和事项内容
- 语音查看日程：支持查看今天、明天、后天或全部安排
- 语音删除日程：按语音关键词删除匹配的日程
- 日程列表展示：按时间顺序展示所有提醒
- 本地保存：使用浏览器 localStorage 保存日程
- 文本备选输入：浏览器不支持语音识别时，仍可输入文字指令体验

## 语音指令示例

可以点击「开始语音」后说：

```text
明天下午三点提醒我开会
今天晚上八点提醒我写周报
后天上午九点半提醒我交作业
查看明天的安排
删除明天下午三点的开会提醒
```

## 技术方案

- HTML / CSS / JavaScript
- Web Speech API：浏览器语音识别
- localStorage：本地保存日程数据
- 无需后端服务，直接打开网页即可运行

## 如何运行

下载或克隆本仓库后，直接用浏览器打开：

```text
index.html
```

建议使用 Chrome 浏览器，并允许网页使用麦克风。
